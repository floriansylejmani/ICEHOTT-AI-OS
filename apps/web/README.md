# ICEHOTT AI OS — Web Frontend

Next.js 16, React 19, TypeScript and Tailwind. This Phase 0 preview intentionally has no login, AI execution or billing.

From `apps/web`:
```bash
npm ci
npm run dev
npm run lint
npm run test
npm run build
npm audit --omit=dev
```
See the monorepo root `docs/MASTER_PLAN.md` for product phases and security requirements.
